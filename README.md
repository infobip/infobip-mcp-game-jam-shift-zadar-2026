# 🌊 Vibe Coding Game Jam — Shift Zadar 2026

Twelve rooms. Twelve crews of attendees riding shotgun with an AI coding agent over
WhatsApp. Zero surfboards, but plenty of wipeouts and glow-ups along the way.

This repo is the tide pool where it all washed up: every game built live during the
**Vibe Coding** game jam at [Infobip Shift](https://shift.infobip.com/) 2026 conference.

## How the waves formed

Each room started as a blank `index.html` and a driver's seat that rotated between
attendees. One person at a time would text an instruction to the agent, it would
crash out a new version of the game, and the room would either ride that wave or
paddle back out and try another prompt. Repeat until the tide (or the conference
schedule) ran out.

Every commit here is one of those waves: a published version of a room's game,
committed in the order it actually broke on the shore, with the agent's own
turn-by-turn summary as the commit message. `git log` on any room is basically a
highlight reel of the game evolving in real time.

| `faded_marble` | 🕹️ 8-bit Tetris, retro CRT green-on-black vibes |

Open any `rooms/<name>/index.html` in a browser to play the final cut. Walk the
`git log` for that folder to watch the swell build, version by version.

## Surf responsibly

These games were built fast, for fun, via WhatsApp — not for production. Treat
them like a beach read, not a load-bearing wall.
